# Contributing to Moneyowl APIs

Thank you for your interest in contributing to **Moneyowl APIs** 🎉  
Contributions of all kinds are welcome — bug reports, feature requests, documentation, and code.

Please take a moment to review this document before contributing.

---

## 📋 Code of Conduct

By participating in this project, you agree to maintain a respectful and inclusive environment.
Harassment, discrimination, or abusive behavior will not be tolerated.

---

## 🧭 How to Contribute

### 1. Fork the repository
Create a fork of the repository on GitHub.

### 2. Clone your fork
```
git clone https://github.com/falcaonicole/Moneyowl_APIs.git
```
