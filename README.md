Moneyowl APIs :  Backend APIs for Moneyowl App

This repository contains the core backend services responsible for authentication,
business logic, integrations, and data processing for Moneyowl.

🛠 TECH STACK

- **Java 21**
- **Spring Boot 3.5.6**
- **Maven**
- **Spring AI**
- **PostgreSQL 18**
- **Docker** 

📦 Prerequisites

Make sure you have the following installed:

- Java 21
- IntelliJ IDEA CE Community version
- PostgreSQL 18
- Docker

⚡ Quick Start

Clone the repository in your desired folder:
````
git clone https://github.com/falcaonicole/Moneyowl_APIs.git
 ````
🔧 Configuration

This project uses environment variables for configuration in the application.yaml file.
Secrets must never be committed to the repository.
